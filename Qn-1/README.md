# U21CS501 – Web Technology | Assignment I – Question 1

**Topic:** How the World Wide Web Works
**Course:** U21CS501 Web Technology | III Year / V Sem / Section A
**Institution:** KPR Institute of Engineering and Technology (Autonomous)

## About this file

`index.html` is a single self-contained HTML5/CSS3 page (no external files or
build step needed) that explains the concepts required by Question 1:

- Internet Overview
- Fundamental Computer Network Concepts
- URL and its Structure
- Domain Name (DNS)
- Web Browsers and Web Servers
- Working Principle of a Website
- Difference between Client-side and Server-side Scripting

Each concept is illustrated with an inline SVG diagram built directly into the
page (no images to lose track of), plus a comparison table for the
client-side vs server-side scripting section.

## How to view it

Just open `index.html` directly in any modern browser (Chrome, Edge, Firefox) —
double-click the file, or right-click → **Open with** → your browser.

## How to upload to GitHub

1. Create a new repository (e.g. `web-tech-assignment-1`).
2. Add `index.html` (and this `README.md`) to the repo.
3. Commit and push:
   ```bash
   git init
   git add index.html README.md
   git commit -m "Assignment 1 - Q1: WWW fundamentals page"
   git branch -M main
   git remote add origin <your-repo-url>
   git push -u origin main
   ```
4. Optionally enable **GitHub Pages** (Settings → Pages → Deploy from `main`
   branch) to get a live link for your submission along with the repo link.
